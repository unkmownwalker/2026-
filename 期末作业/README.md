# 关税模拟系统（Tax System）

本项目是一个基于 Python 的全球关税模拟系统，包含后端业务逻辑和 Tkinter 图形界面。用户可管理国家、商品、关税设置，并支持路径价格计算、最优采购路径搜索以及制造业回流分析。

## 目录

- `backend.py`：包含税制系统核心逻辑，负责国家、商品、生产、关税管理和路径计算。
- `frontend.py`：Tkinter GUI 界面，提供交互式操作、导入/导出数据和结果展示。
- `tax_data.json`：默认数据文件，程序运行时自动加载和保存。
- `tax_data1.json` / `tax_data2.json`：示例数据文件，用于测试或数据备份。
- `README.txt`：项目的简要操作说明。

## 功能

- 国家管理：添加、修改、删除国家；设置国家过境费；国家数量最多 10 个。
- 商品管理：添加商品、设置各国出厂价、取消生产、删除商品。
- 关税管理：配置国家间商品关税率；查看选定商品的关税矩阵。
- 路径计算：输入自定义贸易路径，计算到岸价格。
- 最优采购：寻找指定目的国的最优采购路径。
- 制造业回流分析：分析为保护本国产业所需的关税调整策略。
- 数据导入/导出：支持 JSON 格式的数据文件读写。

## 运行方式

1. 安装 Python 3。  
2. 确保 `backend.py`、`frontend.py` 和 `tax_data.json` 在同一目录下。  
3. 使用命令运行：

```bash
python frontend.py
```

## 使用说明

- 国家代码请使用大写，如 `CN`、`US`、`JP`。  
- 商品名称会在程序内部转换为大写，建议输入时不要包含空格。  
- 路径输入格式示例：`CN->US->JP`，路径中不能包含重复国家。  
- 关税率、出厂价、过境费均不能为负值。

## 数据文件说明

数据文件 `tax_data.json` 的结构如下：

- `countries`：国家代码与信息字典。
- `products`：商品名称列表。
- `production`：生产关系与出厂价格。
- `tax`：出口国-进口国-商品对应的关税税率。

## 开发说明

- `backend.py` 负责业务逻辑实现，包括数据加载/保存、价格计算、最优路径搜索。  
- `frontend.py` 负责图形界面展现，使用 Tkinter 构建标签页、输入框、按钮和文本输出区。

## 备注

- 若程序提示数据不存在，请先在“国家与商品管理”模块中添加对应国家或商品。  
- 导入新数据时会覆盖当前内存中的现有数据，请先备份重要数据。

简单操作说明

1. 运行程序
   - 使用 Python 3 运行 frontend.py。
   - 例如在命令行中执行：python frontend.py。

2. 界面说明
   - 国家与商品管理：添加/删除国家，添加商品，设置出厂价，取消生产，删除商品。
   - 关税管理：设置国家间商品关税，查看关税矩阵。
   - 路径计算与最优采购：输入自定义路径计算到岸价格，搜索指定目的国的最优采购路径。
   - 制造业回流分析：选择本国和商品，分析为保护本国产业所需的关税调整。

3. 数据导入导出
   - 点击顶部工具栏的“导出数据”按钮，将当前数据保存为 JSON 文件。
   - 点击“导入数据”按钮，从 JSON 文件加载系统数据，导入前会清空当前内存数据。

注意事项

- 运行前请确保已有 Python 3 环境，并且数据与程序文件在同一目录下。
- 国家代码统一大写输入，例如 CN、AM、J。
- 商品名称会统一转换为大写存储，建议输入时不要带空格。
- 路径输入格式请使用 A->B->C，且路径中的国家不能重复。
- 关税率、出厂价、过境费均不允许输入负数。
- 如果程序提示数据不存在，请先在国家与商品管理中添加对应的国家或商品。

其他说明

- 程序通过 backend.py 封装业务逻辑，frontend.py 提供 Tkinter GUI 界面。
- 数据存储在 tax_data.json，可直接编辑该文件或通过 GUI 导入导出。
